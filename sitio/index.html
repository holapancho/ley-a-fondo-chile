Las leyes de Chile, citadas artículo por artículo.

Una skill para tu agente de IA que descarga la norma desde Ley Chile – Biblioteca del Congreso Nacional, la indexa en tu equipo y responde con cada afirmación citada: artículo, fecha de versión y link oficial. Antes de responder, el agente verifica sus citas contra el texto oficial.

› ¿Un accidente camino al trabajo cuenta como accidente del trabajo?

Sí. La Ley 16.744 lo llama accidente de trayecto:

«Son también accidentes del trabajo los ocurridos en el trayecto directo, de ida o regreso, entre la habitación y el lugar del trabajo»

Ley 16.744, art. 5 (texto desde 2006-04-28; versión de la norma 2021-12-10)

Excepciones: «Exceptúanse los accidentes debidos a fuerza mayor extraña que no tenga relación alguna con el trabajo y los producidos intencionalmente por la víctima.» (Ley 16.744, art. 5)

Hipotético: una trabajadora se cae de la bicicleta en su ruta habitual de la casa a la oficina. Es un accidente de trayecto.

Cómo funciona

Todo corre en tu equipo con un solo script de Node.js, sin dependencias. La skill descarga solo lo que pides.

Pides una norma

"Carga la ley 20.000" o "carga el código del trabajo". La skill la baja de Ley Chile con todos sus reglamentos y la indexa en ~/.ley-a-fondo-chile/.

Preguntas

El agente busca en el índice, lee los artículos completos, sigue las remisiones y los reglamentos, y traduce las penas citando el Código Penal.

Verifica

Antes de responder, el agente comprueba que cada artículo citado exista, que cada link apunte al artículo que nombra y que cada texto entre «» sea idéntico al oficial.

Responde con citas

Tabla resumen, detalle caso a caso, texto literal de las penas y ejemplos marcados como hipotéticos. Si la ley no responde la pregunta, lo dice.

Instalar

Elige tu agente. La skill necesita Node.js 24 o superior y acceso a internet hacia leychile.cl.

Como plugin, desde el marketplace de este repositorio. Dentro de Claude Code:

/plugin marketplace add holapancho/ley-a-fondo-chile
/plugin install ley-a-fondo-chile@ley-a-fondo-chile

O desde la terminal:

claude plugin marketplace add holapancho/ley-a-fondo-chile
claude plugin install ley-a-fondo-chile@ley-a-fondo-chile

Para actualizar: claude plugin update ley-a-fondo-chile@ley-a-fondo-chile.

Con el instalador de Agent Skills (npx skills), que detecta los agentes que tienes instalados:

npx skills add holapancho/ley-a-fondo-chile

Para un agente en particular, o para todos tus proyectos (-g):

npx skills add holapancho/ley-a-fondo-chile -a codex -g
npx skills add holapancho/ley-a-fondo-chile -a cursor
npx skills add holapancho/ley-a-fondo-chile -a claude-code -g

El instalador npx skills pide Node.js 22.20 o superior.

  1. Descarga ley-a-fondo-chile.zip (última versión).
  2. En claude.ai, abre la configuración, busca la sección de Skills y sube el .zip.
  3. La ejecución de código tiene que estar activada y con acceso a internet hacia leychile.cl y nuevo.leychile.cl. En cuentas de organización, eso lo habilita un administrador.

Copia la carpeta skills/ley-a-fondo-chile en la carpeta de skills de tu agente. Por ejemplo, en Claude Code:

git clone https://github.com/holapancho/ley-a-fondo-chile
cp -r ley-a-fondo-chile/skills/ley-a-fondo-chile ~/.claude/skills/

Prueba que funciona:

node ~/.claude/skills/ley-a-fondo-chile/scripts/ley-a-fondo.mjs estado

Qué puedes preguntar

Penas

"¿Cuáles son las penas por porte de droga?" El agente distingue consumo personal, microtráfico y tráfico, y traduce los grados de las penas citando el Código Penal.

Códigos

"¿Qué dice el art. 18 quáter del Código del Trabajo?" o "¿Cuáles son las fuentes de las obligaciones según el Código Civil?"

Decretos y reglamentos

Cualquier ley, decreto, DFL o decreto ley publicado en Ley Chile, junto con los reglamentos que la desarrollan y sus anexos.

Limitaciones conocidas

Solo la versión vigente

No se pueden consultar versiones anteriores de una norma.

Tablas en imagen

Algunas tablas, como la escala de penas del art. 56 del Código Penal, están publicadas como imagen. Sus datos no se pueden verificar como texto, y el agente lo advierte.

Normas fuera de Ley Chile

Las normas que no están en Ley Chile, como las de la CMF, no se pueden cargar. De algunas circulares, BCN solo publica un extracto.

Servicio no documentado

La skill usa los mismos endpoints públicos que usa el sitio de Ley Chile. Como no están documentados, podrían cambiar; una prueba semanal avisa si eso pasa.

Aviso legal

Las respuestas no son una interpretación oficial de la Biblioteca del Congreso Nacional ni asesoría legal. Para un caso concreto, consulta a un abogado.

Los textos legales vienen de Ley Chile – Biblioteca del Congreso Nacional. Cada respuesta cita la fuente y la fecha en que se obtuvo el texto. La skill descarga solo lo que pides y no replica Ley Chile.

Este proyecto es independiente y no tiene relación con la Biblioteca del Congreso Nacional.
